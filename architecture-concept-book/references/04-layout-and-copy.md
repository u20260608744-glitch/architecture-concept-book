# 版式、文字与阅读秩序

## 从参考中提炼规则

实际查看参考册的封面、正文、图纸、分析、数据和跨页，不只提取文字。记录页面比例、留白、网格、标题层级、字体搭配、主图比例、图注、页脚、图例与深浅页节奏。把这些关系抽成规则；不复制其商标、文案、未获许可的图片和项目事实。

用户没有指定风格时，可按读者与图纸密度选择白纸技术、自然编辑、竞赛图板或单色作品集等方向。给出简短选择理由，避免不必要的多个主题切换。风格服务内容，不能把技术图压成装饰缩略图。

## 建立最小视觉系统

- 页面：尺寸/横竖、是否按双页阅读、装订边和安全区。
- 网格：边距、栏数、栏间距、基线和主图轨道。
- 字体：中英文、数字、单位、标题与正文的字体和字重；确认嵌入许可。
- 色彩：背景、文字、强调色、数据/功能语义色分别定义。
- 组件：章节头、页标题、主图、图注、指标表、来源、页脚/页码。
- 图纸：边界线、退线、指北针、比例尺、标签和图例规则。

这些是当前册子的配置，不是永久默认。中文、英文或双语要分别试排，不靠把字体无限缩小维持相同换行。

## 按页面任务选择构图

| 类型 | 组织建议 | 主要检查 |
|---|---|---|
| 封面/主张 | 一个清楚的视觉焦点与项目识别 | 是否过空或主张不明，是否误用案例照片 |
| 场地分析 | 图与分析结论相邻，图例和参数可读 | 边界、尺度、来源，切换地图时的同构图 |
| 总图 | 主图与指标侧栏构成同一阅读任务 | 图幅、比例尺、方向、上下边界对齐 |
| 方案/空间 | 主图交代关系，辅助图说明差异 | 主次、裁切、图注和方案 ID |
| 功能/日照 | 比较图共用尺寸与文字行轨道 | 建筑投影大小、图例、未知区域 |
| 数据/取舍 | 表格单位与口径清楚，结论有依据 | 精度、宽度、表头、合计与说明 |
| 表现 | 接近使用者的空间体验或整体关系 | 实际体块、两点透视、灯光和场景约束 |

## 图文对齐

比较列共享标签、图、数字和解释的纵向轨道。标题靠近所属图，不黏着上一段说明；条形图标签与自身色块相连，不挤进上一行图例。左右图文的底线和分隔线一起规划，不能通过加大量无意义空白实现对齐。

源图完整阅读采用 contain。展示图可裁周边，但不能裁关键建筑、图例、尺度和解释。裁图、放大、比例尺和矢量图坐标一起处理。图片始终等比，不拉伸。

方案多时分组或分页，不把任意 N 个方案塞进极窄列。对同组模型保持比较尺度或明确标明独立缩放，不把相同图框当成相同建筑大小。

## 文字编辑

页标题说明观点，正文解释原因，图注交代对象与条件，来源支持事实。不要在同页顶部按钮、标题、卡片和图片旁重复同一方案名。减少“本方案通过……从而打造……”的空转句，直接说做了什么、影响什么、怎样由图支持。

给文本组件设实际高度预算并自动换行，溢出时优先改写或调整构图。长中文、带单位数字和混合英文要单独检查；不要让脚注压到页脚或正文覆盖表格第一行。表头与数据行不能产生不清楚的换行归属。

小字在实际阅读尺寸下检查。技术标注若读不清，应增加图幅或分图，而不是把不可读视为“高级留白”。页脚来源能找到，不必将所有内部实现细节铺到主视觉上。

## 数据表和图例

数值右对齐、小数位统一，单位放表头或稳定后缀。计数保持整数。突出当前比较项时不要让字体、行高或文字基线跳变。功能比例的分母必须明示；表格合计来自相同事实。

图例顺序、颜色和标签全册固定。零值与无数据不是一回事；没有结果可显示“待核/未纳入统计”，不能给零色块。条形图的留白/未分配量要解释。

## 先小样再展开

先测试代表性的分析、总图、表现和数据页。核对最长标题、最复杂图纸和最多列的表，而不是只试最简单封面。把验证后的组件用于全册，仍需逐页检查实际内容。风格已由用户确定时直接沿用并执行，不为了流程形式重复询问。
