# 从分析到设计叙事

## 先定义这本册子要帮助什么判断

业主选择方向、内部评审、概念竞赛、市场介绍、改造沟通和作品集展示，关注点不同。先把读者读完后要做的判断写成一句话，再选择资料与篇幅。不要把所有已有文件按文件夹顺序装订成册。

## 分析卡

每个准备保留的分析填写：

```text
问题：需要决定什么？
证据：来源、日期、范围、可靠程度。
发现：资料实际显示什么？
影响：它影响哪些空间/人群/时段？
设计动作：保留、打开、连接、遮蔽、错动、分层、减小或加强什么？
图证：用哪张总图/剖面/流线/对照/现场图支持？
限制：还有什么不能从现有资料确定？
```

“周边绿化好”不能直接推出“项目有森林直达入口”。应区分可见林缘、合法入口、公共通行和实际步行路线。设计回应可以是种植缓冲、朝向与框景，图上需对应具体位置。

## 按任务选择分析

| 模块 | 核心问题 | 资料与表达 |
|---|---|---|
| 区位与到达 | 人和车怎样抵达、在哪发生转换？ | 已核道路、入口、交通节点；路线与距离口径 |
| 景观与视野 | 哪里值得打开，哪里需要隐私？ | 地形、照片、周边高度/开口；视线和剖面 |
| 配套与日常 | 哪些生活过程可借外部，哪些需项目补充？ | 真实设施、营业/可达信息；圈层与路径区别 |
| 邻里与高度 | 近界压迫、遮挡和远景有什么差别？ | 测绘/模型/公开数据的高度与估计分类 |
| 气候与日照 | 哪些位置/季节/时间受到影响？ | 真北、坐标、方法、采样对象；参数和限制 |
| 市场与产品 | 产品是否适配实际使用和人群？ | 已核案例、平面、面积口径；本地与区域案例区分 |
| 场地控制 | 边界、退线、地形和出入口如何限制设计？ | 控制资料和标高；不把假设退线当法定批准 |
| 功能与流线 | 公共、私密、服务和消防如何组织？ | 平剖面、使用过程；语义映射与待核范围 |
| 构造与实施 | 悬挑、开洞、竖向与设备如何协调？ | 实际设计深度支持的结构/机电问题 |

分析数量不作为质量指标。保留能改变设计判断的分析；没有资料的题目可以列下一阶段任务，不编造成已完成。

## 形成主线

一种可调的顺序是：任务与目标 → 场地发现 → 设计回应 → 空间/形体 → 总图与组织 → 使用与体验 → 性能/指标 → 取舍和下一步。不是每本册子都需要全部模块。

单方案讲“为何这样组织、使用者怎样体验、仍需验证什么”。多方案先说明共同约束与区别，再用一致视图和指标比较。不能先选一个最漂亮效果图，再倒写它已满足所有要求。

### 项目类型的差异

- 住宅：户型、公共/私密、日照、到达、生活配套与多层级花园。
- 办公：工作方式、公共与可租边界、核心/效率、服务和弹性。
- 商业：到达、可见性、楼层联动、业态与后勤。
- 公共建筑：服务人群、公共性、无障碍、流线与运营。
- 室内：现状、行为路径、收纳/功能、材质、灯光与尺度。
- 景观/城市：地形、水、生态、连接、活动、分期与维护。
- 更新/作品集：保留与介入、个人角色、设计证据和实际贡献。

## 写作层级

1. 册子主张：简短，说明主要设计关系，不承诺无证据的绩效。
2. 章节标题：指明议题或发现。
3. 页标题：读者看图前知道这页要说明什么。
4. 主文：证据和动作，通常一到三段；长度取决于版式和阅读距离。
5. 图注：对象、视角、时刻/楼层、比例或分析条件。
6. 来源与限制：准确但不过度占据视觉主位。

句式示例：

```text
发现：近界一侧与邻栋距离较紧，主要景观位于另一侧。
回应：将公共到达与种植缓冲放在近界侧，主要起居空间朝向开敞景观。
图证：总图标出入口与缓冲带；剖面显示起居视线和邻界关系。
限制：具体窗位与隐私仍需下一阶段平面验证。
```

少用“赋能、打造、极致、高端、地标”等不能被图纸证明的空词。文字中每个数字都绑定事实表；未完成的设计用“拟、建议、意向、待核”表达，不能用将来时包装成事实。

## 案例解读

先核实项目、作者、地点、时间、原始图像来源和相关事实。写“可借鉴原则 → 与本项目差异 → 本项目转译”，而不是只放项目名与赞美。参考平面与本项目平面要明显分开；不同面积口径不能直接比较。第三方案例不能充当本方案已建成照片。

## 逐页计划

每页的结论、主图、事实、正文和图注同时规划。图只是装饰且不能支持结论时，换图或换结论。正文和图重复介绍同一名称时删去冗余层级。页数根据内容调整：增加一页应增加信息或改善阅读，而不是填满预设目录。
