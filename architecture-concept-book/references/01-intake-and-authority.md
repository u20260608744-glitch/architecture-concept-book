# 资料、版本与权威

## 开始时的最小闭环

1. 阅读用户本次要求，区分制作册子、设计深化、原模型修改和外部发布；四者不自动互相授权。
2. 清点指定资料与现有成果，读文件内容而不是只看文件名。扫描件先识别文字并查看原页。
3. 确认读者、用途、阶段、语言、风格方向、最终格式。资料已有答案就不重复问。
4. 建立能力表和真正缺项，开始不依赖缺项的内容。
5. 把关键源文件的版本和哈希固定下来。不同日期的同名文件不能混用。

## 各类资料如何使用

| 资料 | 可以支持 | 不可直接推出 |
|---|---|---|
| 设计任务书/用户明确说明 | 项目目标、产品、约束、已确认参数 | 未给出的几何与法定批准 |
| 测绘/边界/CAD | 对应图框内的尺度、轮廓、局部文字 | 其他图框的层高和屋顶标高 |
| 原生模型与可信导出 | 对象层级、现有形体、相机、可解析材质 | 完整 BIM、合法计容、准确套数 |
| 经济指标表 | 明示口径的指标 | 与当前模型自动一致 |
| 原册/PDF | 当时版本的图文、版式、页序 | 当前模型已无变化 |
| 场地照片/卫星/地图 | 对应位置与时间的可见信息 | 精确地籍、步行距离或产权 |
| 参考案例/参考册 | 已核案例事实和授权的表达方向 | 本项目已具备案例的设施、认证和收益 |
| 生成式图片 | 构图、材料和空间气氛意向 | 面积、楼层、结构和道路的计量依据 |

## 建立可追溯的来源记录

关键字段：稳定 `source_id`、相对路径、类型、版本日期、SHA256、读取状态、权威范围、图框/页码/对象定位、许可或署名。对照片记录拍摄位置/方向；对模型记录单位、世界变换、方案范围和相机；对法规记录地区、版本和核实日期。

模型变换要递归展开，保留对象路径/实例变换/层级和来源 ID。不要因颜色相似就认定功能。图框文字只对所属图框生效；缺失字段为 null/unknown。不同建筑、不同屋顶的标高分别记录。

### 资料冲突

按用户最新明确指定的权威范围处理。任务书可能控制功能，当前模型控制体量，测绘控制边界，参考册控制风格；不能设一个文件对所有事实都自动最高。记录冲突、影响页和解决状态。无法解决时继续其他工作，把该结论标为待核。

缺项分三类：阻塞指定能力；可继续但须 unknown；只影响表现的可选项。不要把缺一个项目阶段名称当成不能排版，也不要把缺真北当成可以默认朝上就是北。

## 文件与许可

原始模型、图纸、照片和 PDF 保持只读；工作副本与导出文件独立。读取正在使用的原生文件时优先安全的只读导出/快照，不重启或覆盖软件中的未保存工作。

第三方素材记录来源、作者、可用范围。引用不等于具有重新分发权。公开 Skill 或方法介绍时默认只公开原创方法、脚本和合成示例；不把客户图纸、商业参考册、照片、字体文件、账号、绝对机器路径或访问密钥打包进去。

## 初次输出范式

用几句话说明：已经读到的关键资料与可实现能力；真正缺少什么以及影响；现在会先完成什么。随后给出具体页面/图版方向并执行。只有阻塞准确性的条件才需要用户补充，不能反复索取已提交信息。
