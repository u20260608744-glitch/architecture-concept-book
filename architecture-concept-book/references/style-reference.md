# 把参考册转成可执行的风格

参考册是正式输入，不是完成排版后随手模仿一张封面。用户上传了 REF 时，先实际读取代表页，并把“喜欢什么”拆清；不要自动回到通用模板、任意深色科技风或只替换配色。

## 1. 登记参考的作用

记录 `ref_id / 文件及哈希 / 页码或图位置 / 参考维度 / 用户原话 / 本项目落实方式 / 不采用项`。完整册和局部截图可以互补：整册控制节奏，截图可指明具体材质或按钮等局部。不同 REF 分别控制版式、文字、图纸或效果图；冲突按用户最新说明解决。

| 维度 | 应查看与记录的内容 |
|---|---|
| 成品形态 | 单页/跨页、页幅、长宽比、页数节奏、屏幕/印刷使用方式 |
| 网格与留白 | 外边距、分栏、栏间距、标题/图顶线、图框、跨页关系、信息密度 |
| 字体与色彩 | 标题/正文/注释的尺寸关系、字重、行距、段距、中英比例、色彩角色 |
| 叙事与文案 | 标题讲主张还是内容、正文怎样用证据解释空间、图注/数据如何支持判断 |
| 图纸与分析 | 背景、线重、边界、北针、图例、比例尺、强调色、数据图与标注位置 |
| 图片与镜头 | 主体占比、裁切、两点透视/轴测、视高、远近、前景、焦点、景深、天际线 |
| 建筑表现 | 允许借鉴的材料、色彩、阳台、栏杆、窗框、灯光、绿化、时间和情绪 |
| 页脚与品牌 | 页码、目录、项目名、来源、标识位置；仅使用本项目有权使用的资产 |

尺寸能测量则测量；从截图估计的比例注明近似。字体先判断层级与形态，再选可用且有权使用的字体。缺少字体不妨碍做等效层级，但不能说已经嵌入原字体。

## 2. 做风格说明与内容转译

使用 [参考提交/转译表](../assets/style-brief.md)，写出简短的可执行规则，例如：

- 双页以大图建立空间理解，分析页用少量文字解释设计动作；不是每页都堆满小图。
- 标题、图注和页脚有固定对齐轨道；同类方案共用信息层级与图幅。
- 标题写本项目的判断，正文写事实如何产生空间回应；删掉只重复标题的旁白。
- 参考图控制材质/灯光/构图；体块、楼层、退台、道路和邻栋位置以当前模型为准。

这些是示例，不能在没有 REF 支持时当成所有项目默认。用户已授权的具体表达应逐项落实，不把“参考风格”缩减为泛泛形容词。

## 3. 用本项目写文字

先列本项目的设计问题、证据、动作、空间结果和待核问题，再转成参考册的阅读节奏与语气。可以参考“短标题 + 一段空间说明 + 数据图注”的结构，但主张、地名、户数、设施、认证、价格和市场判断必须来自本项目。

例：参考册讲“林间安静的回家路径”，新项目应先有真实到达和林缘关系，再写对应空间；不能因参考册出现花园、SPA、泳池就给新项目增加这些设施。案例事实与设计愿景要明确区分。

## 4. 建筑表现的转译

用户同时授权建筑风格时，用当前模型导出底图锁定主体与环境，再把材质、颜色、阳台语言、栏杆、窗框、灯光和植栽气氛映射到获准范围。记录相机，先核轮廓/层数/洞口/平齐关系/退台，再核道路、邻栋、入口和树位。

如果用户要求近景、密植、两点透视、前虚后实，就在镜头和表现记录中逐项验证；不要仅把这些词写入提示词便称已实现。两点透视检查竖向保持平行；景深不能遮掉需要核对的主轮廓。生成图不用于面积或技术图测量。

## 5. 用代表页检查转译

选择能覆盖差异的页面：封面/章节开篇、场地分析、总图或方案表达、数据比较。把参考观察和实际代表页并排核对：网格、字体层级、留白、主图大小、图文节奏、语气、图纸线型与配色，记录具体偏差并修正。

用户要求先看小样时先交小样；已授权全册时完成内部核对后继续，不把此流程当成额外审批。最终全册还需复查，同一个风格不能只在前几页成立。

## 6. 公共展示

公开预览可使用原创演示；当项目所有者明确要求展示其已完成成果时，直接选取获准的实际成果，保留原署名和来源版本，并按授权范围公开。不要把其请求误改成重新制作的示意图。第三方brochure、完整客户原件和字体文件不因此自动获得再分发许可；项目预览与方法包的许可分别记录。
